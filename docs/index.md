# Visual Place Learning

How does a fly learn a place? This project develops an accessible thermal–visual arena for studying spatial learning in freely walking *Drosophila melanogaster*. Eight LED panels provide visual landmarks around a 20 cm arena; independently controlled target channels change the thermal landscape. Ten five-minute training trials connect controlled stimulation to individual trajectories.
