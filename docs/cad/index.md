This section will document each printed part separately. The spaces below are reserved for photographs, part descriptions and model files. The groups are provisional; final names, dimensions and assembly instructions will be added when each part is identified.

<div class="note"><strong>Part descriptions and model files are pending.</strong> Print dimensions and assembly instructions will be added with the confirmed files.</div>

**CAD** is the editable computer model of a component. A **STEP** file preserves model geometry for further design work. **STL** and **3MF** files are commonly used to prepare a print. Keep the editable model and the file used for printing together so a later adjustment can be traced to the correct part.

## What each part record will contain

| Field | Information to add |
| --- | --- |
| Function | What the part holds, joins or positions |
| Location | Where it sits on the assembled arena |
| Interfaces | Component dimensions, hole spacing and surfaces that must fit |
| Fasteners | Screw, nut, insert or pin sizes and quantities |
| Printing | Material, orientation, supports and settings actually used |
| Assembly | Order of fitting and any adjustment needed |
| Verification | How to check fit, alignment and stability |
| Files | Editable STEP model and print-ready STL or 3MF |
